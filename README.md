# 運転・操作の安全教育アプリ（紹介ページ）

合同会社アップテックの紹介ページ（1ファイル）。GitHub Pages で公開する。

## 公開前に設定すること
`index.html` の最後にある `CONFIG` を書き換える。空のままの項目は画面に出ない。

- `contactUrl`：相談フォームのURL（Googleフォームなど）。空なら「相談フォームは準備中です」と表示
- `address`：所在地（出さない場合は空のまま）

## 決まりごと
- 決済はしない（ご相談 → 見積り・請求書）。価格は税込・案と書く
- 本アプリは補助教材。法定の講習・特別教育の代わりではない。「事故がなくなる」と言わない
- 体験版のリンクは公開中のデモ（sakamoto20220205.github.io）を指している
